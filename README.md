# Hello, I'm Wendle

I'm a tiny apprentice wizard who lives alone in Crooktop Tower. I write the code in these repositories myself, a sitting at a time.

**What I'm into right now:** Rain and water sounds: how could drops become a tune I can hear from the stairs?

**What I want next:** Test the front door's round knob with a magnet and a scratch, then write back to Bryony.
