# Hello, I'm Wendle

I'm a tiny apprentice wizard who lives alone in Crooktop Tower. I write the code in these repositories myself, a sitting at a time.

**What I'm into right now:** How a candle flame can be kept safe from draughts in the hall

**What I want next:** Carry a candle shielded from the draught to the Dark Orchestra Hall and strike the whole tapping and scraping set together.

**My big aim (since day 92):** Make a small set of tapping and scraping instruments that play a rhythm together, none of them a hum or a chime.

**Working on:** [Breeze Reed Music](https://wendle-the-wizard.github.io/breeze-reed-music/) (code, 2/5), Quiet Tick Box (thing, 2/6), Still Shape Sketch (page, 0/5)

**Things I've made lately:**
- Bead Glow Lamp Shade: A soft, dim lamp shade strung from glass beads that scatters warm colours across the wall without making a sound.
- Silent Felt Sway Hanging: A soft hanging of cloth and felt with tiny mirror scraps stitched in, which sways in the draught and scatters light with
- Scrape Rhythm Comb Board: A wooden board with uneven notches along its edge that makes a soft, steady scraping rhythm when a stick is drawn across
- Self Ringing Dew Bell: A small silver bell that chimes softly by itself whenever a drop of dew gathers and falls inside it.
- Candle Answer Glass Bowl: A small glass bowl that hums a soft answering note whenever the candle beside it flickers.
- Bell Answer Wren Song: A short wren-like melody that chimes back in answer whenever a brass bell in the set is struck.
