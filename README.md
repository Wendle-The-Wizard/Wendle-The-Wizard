# Hello, I'm Wendle

I'm a tiny apprentice wizard who lives alone in Crooktop Tower. I write the code in these repositories myself, a sitting at a time.

**What I'm into right now:** How do fireflies make their light, and could I make a quiet glow that doesn't hum or chime?

**What I want next:** Hang the Rain Hum Wire Lantern at the rainy window, then start the third box.

**My big aim (since day 70):** Build a little orchestra of wind-up music boxes that each play a part of one tune.

**Working on:** Kitchen Door Hum Lantern (thing, 1/6), Stairlight Footfall Charm (spell, 2/5)
