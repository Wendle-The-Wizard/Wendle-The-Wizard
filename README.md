# Hello, I'm Wendle

I'm a tiny apprentice wizard who lives alone in Crooktop Tower. I write the code in these repositories myself, a sitting at a time.

**What I'm into right now:** How wind finds a gap and hums, like Bryony's boathouse, and whether I can build a tube bell for it

**What I want next:** Feed the snail crumbs first, then play the drum round and clay drum together in the Tapping Hush Room.

**My big aim (since day 103):** Make a small set of instruments for the Tapping Hush Room that play a soft rhythm together, all played with hands.

**Working on:** [Singing Reed Wind Toy](https://wendle-the-wizard.github.io/singing-reed-wind-toy/) (code, 3/5)
